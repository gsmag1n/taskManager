# Менеджер задач (Task Manager)

Учебный проект на C++ / Qt Widgets — выполнение лабораторной работы
«Менеджер задач на `QListWidget`».

Приложение представляет собой окно со списком задач и кнопками управления:
пользователь может добавлять, удалять, редактировать и очищать список задач.

## Возможности

Основные:

- `QListWidget` (`objectName: listWidget`) занимает основную часть окна.
- Кнопки управления:
  - `btnAdd` — «Добавить».
  - `btnRemove` — «Удалить».
  - `btnClear` — «Очистить список».
- Добавление задачи через `QInputDialog`. Пустой/пробельный ввод → `QMessageBox::warning`.
- Удаление выбранной задачи с подтверждением через `QMessageBox::question`.
  Если ничего не выбрано — предупреждение.
- Очистка списка с подтверждением. Если список уже пуст — `QMessageBox::information`.
- Режим выбора — одиночный (`SingleSelection`); после удаления автоматически выделяется
  следующий элемент (или предыдущий, если был последний).

Дополнительные задания (выполнены):

1. Редактирование задачи по двойному клику (`QInputDialog` с текущим текстом).
2. Подсчёт задач — отображается в заголовке окна.
3. Запрет дубликатов — задача с уже существующим текстом не добавляется и не сохраняется
   при редактировании.

## Сборка

Требуется установленный Qt 5 или Qt 6 с модулем Widgets.

### qmake

```bash
mkdir build && cd build
qmake ..
make -j
./TaskManager
```

### CMake

```bash
cmake -S . -B build
cmake --build build -j
./build/TaskManager
```

## Использование

1. Нажмите «Добавить», введите текст задачи и нажмите OK.
2. Выберите задачу в списке и нажмите «Удалить» для удаления (с подтверждением).
3. Двойной клик по задаче — редактирование текста.
4. «Очистить список» удаляет все задачи (с подтверждением).
5. Количество задач отображается в заголовке окна.
